✨ Quick-Start Setup Guide

Siv is Installed! Let's Connect Your Agent

Follow these 4 simple steps to assign permissions, connect your Agentforce reasoning engine, and run your first AI Sales Brief.

⏱️ Total Time: ~5 Minutes
🔒 100% Native & In-Org (User Mode)
⚡ Zero Custom Code Required
1

Assign Siv Permission Sets

Estimated time: 1 minute

Salesforce requires administrators to grant package permission sets to users before accessing custom objects, tabs, and analytics workspaces.

  1. In Salesforce, navigate to Setup → Users → Permission Sets.
  2. Locate and assign the following permission sets to your users:
raidii__Siv_Admin

Siv Administrator: Grants access to Siv Admin console, prompt template management, and agent publishing controls. Assign to Salesforce Admins.

raidii__Siv_User

Siv User: Grants access to the Siv Console, Siv Briefs workspace, story execution, and AI Assistant chat. Assign to Sales Reps and Managers.

Standard Agentforce Permissions: Make sure your administrator user also has the standard Salesforce permissions: EinsteinGPTPromptTemplateUser and AgentPlatformBuilder enabled on their user profile or assigned permission sets.
2

Open Siv Admin & Copy Agent Script

Estimated time: 30 seconds

Siv packages a pre-configured Agentforce prompt script that instructs the Atlas reasoning engine how to dynamically route sales queries and synthesize briefs.

  1. Open the App Launcher (the 9 dots icon in the top left) and search for Siv.
  2. Select the Siv Admin tab (or navigate directly to /lightning/n/raidii__Siv_Setup).
  3. Click on the Agent Setup sub-tab.
  4. Click the blue "Copy Agent Script" button. The script is instantly copied to your clipboard.
Siv Admin → Agent Setup tab 1-Click Copy Agent Script
3

Create & Activate Agent in Agentforce Studio

Estimated time: 2 minutes

Now, register your new AI agent inside Salesforce's native Agentforce Studio.

  1. In Salesforce Setup, navigate to Agentforce Agents (or go to /lightning/setup/EinsteinCopilot/home).
  2. Click the "+ New Agent" button in the top right.
  3. Select Agentforce Employee Agent and click Create Agent.
  4. Fill in the basic agent details:
    • Agent Name: Siv Agent
    • API Name: Siv_Agent
    • Role: Sales Intelligence & Revenue Strategy Assistant
    • Company: Your company name
  5. In the Agent Instructions text area, simply Paste (Ctrl+V / Cmd+V) the script you copied in Step 2.
  6. Click Save, then click Activate in the top header.
Agentforce Studio → New Agent Modal Select Employee Agent & Activate
4

Verify Connection & Run Your First Brief

Estimated time: 1 minute

Your Siv Agent is now fully operational! Let's verify the active connection and run your first executive brief.

  1. Return to Siv Admin → Agent Setup. The setup card will automatically display an Active (Green) status with your live Agent ID.
  2. Click on the Siv Briefs tab in the navigation bar.
  3. Siv automatically seeds your 4 starting revenue briefs:
    • Pipeline Velocity & Hydrodynamic Flow
    • Account 360 & Lifetime Value
    • Customer Retention & Dormancy Analysis
    • Rep 1-on-1 Coaching & Progression
  4. Select Pipeline Velocity & Hydrodynamic Flow and click the blue "Run" button.
  5. Within 8–10 seconds, Siv synthesizes your active CRM opportunities, trailing 14-day velocity, and stalled risk factors into an executive summary report!
  6. Try asking a question in the right-hand Siv Assistant Chat (e.g., "What is our active pipeline by stage this quarter?") to see Agentforce Atlas reasoning in real time.

Frequently Asked Questions & Troubleshooting

Why did Salesforce display "This app is taking a long time to install"? +
Because Siv contains comprehensive custom objects, LWC components, and packaged prompt templates, Salesforce compiles the components asynchronously in your org. This typically takes 60–90 seconds. Simply click "Done" when prompted; Salesforce will finalize the installation in the background and send you an email confirmation.
Why did Salesforce ask to approve Third-Party Access for api.salesforce.com? +
Siv interacts natively with Salesforce's official Agentforce reasoning APIs and Tooling APIs. All communication remains strictly within the Salesforce ecosystem using secure HTTPS (TLS 1.3) protocols. No data is transmitted to unauthorized external third-party servers.
How does Credit and Token Metering work? +
Siv includes an integrated real-time credit meter visible directly in the top bar. Every Brief run and Chat turn logs prompt tokens, completion tokens, and calculated credit burn into Siv_Log__c with zero cost surprises.
What should I do if the Siv tabs look empty? +
Ensure you have assigned the Siv Administrator (raidii__Siv_Admin) or Siv User (raidii__Siv_User) permission set to your user account (see Step 1).
Where can I get support or report questions? +
Reach out directly to the Siv engineering team at hello@raidii.com or open an issue on the official GitHub Repository.
